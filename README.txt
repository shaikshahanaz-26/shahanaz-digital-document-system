SHAHANAZ DIGITAL DOCUMENT MANAGEMENT SYSTEM

Requirements:
- Node.js installed
- MySQL Server and MySQL Workbench

Setup:
1. Extract this ZIP.
2. Open the project folder in VS Code.
3. Open database.sql in MySQL Workbench and execute it.
4. Copy .env.example to a new file named .env.
5. Update DB_PASSWORD in .env with your MySQL password.
6. Open terminal in this project folder and run:
   npm install
   npm start
7. Open http://localhost:3000
8. Register a new account and log in.

Uploads are created automatically by server.js.
